# State v. Angelucci

## Majority

No judgment having been entered as provided by V.R.Cr.P. 32(b) the cause is returned to District Court, Unit No. 5, Washington Circuit, where jurisdiction still remains. There being no jurisdiction in this Court, the application for bail is dismissed.
