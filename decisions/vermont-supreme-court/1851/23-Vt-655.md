# Woodman v. Stearns

## Majority (By the Court!)

By the Court!
We understand the auditor in this case to have found, that Lancaster’s charge for the work done by the plaintiff was unreasonable, — that it was $5,00, when it should have been but $4,00. And this we can only suppose is with reference to the dealing between the parties, and in the mode of payment there contemplated ; otherwise it would have no proper application to the case. And the cash price for this same work seems to have been much less, — $2,50 or $3,00. Judgment affirmed.
